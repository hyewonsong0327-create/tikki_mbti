# 🎫 틱키의 잃어버린 티켓 · 나의 공연 MBTI 게임

## 폴더 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 게임 전체 (그래픽, 배경음악, 결과 화면) |
| `shows.json` | **직접 고른 추천 공연 목록**. 여기만 고치면 추천 공연이 바뀌어요 |
| `api/shows.js` | KOPIS에서 '지금 공연 중 / 곧 개막' 공연을 자동으로 받아오는 버셀 함수 (선택) |

## 추천 공연은 어떻게 골라지나요?

결과 화면을 여는 **그날 날짜**를 기준으로 자동으로 골라요.

1. 이미 끝난 공연은 빠지고, **지금 공연 중**이거나 **45일 안에 개막**하는 공연만 후보가 돼요.
2. 후보마다 점수를 매겨요.
   - `types`에 내 MBTI가 들어 있으면 가장 큰 점수
   - MBTI 글자별 장르 궁합 (E→콘서트, I→클래식·연극, N→뮤지컬·무용, T→연극, F→뮤지컬 …)
   - `months`에 이번 달이 들어 있으면 시즌 추천 점수 (예: 12월의 호두까기인형)
   - 지금 공연 중이거나 마감이 임박하면 조금 더 높게
3. 같은 장르만 몰리지 않게 섞어서 3편을 보여줘요.
4. 카드에는 `지금 공연 중` · `D-12 개막` · `마감 임박 D-3` · `오픈런` 배지가 자동으로 붙어요.

## ✏️ 공연 추가·수정하는 법 (가장 쉬운 방법)

1. 깃허브 저장소에서 `shows.json`을 열고 연필(✏️ Edit) 버튼을 눌러요.
2. `"shows": [` 아래에 공연 하나를 복사해서 붙이고 내용만 바꿔요.
3. **Commit changes**를 누르면 버셀이 1분 안에 자동으로 다시 배포해요.

```json
{
  "id": "hamlet",
  "title": "연극 <햄릿>",
  "genre": "play",
  "start": "2027-01-10",
  "end": "2027-02-20",
  "venue": "국립극장 해오름극장",
  "region": "서울 중구",
  "url": "https://예매페이지-주소",
  "types": ["ISTJ", "INFJ", "INTJ"],
  "months": [1, 2],
  "poster": "https://포스터-이미지-주소 (없으면 이 줄을 지워요)"
}
```

| 항목 | 설명 |
|---|---|
| `id` | 영어로 된 고유 이름 (겹치지 않게) |
| `genre` | `musical` 뮤지컬 · `play` 연극 · `concert` 콘서트 · `classic` 클래식 · `dance` 무용·발레 |
| `start` / `end` | `YYYY-MM-DD` 형식. 오픈런이면 `"end": null` 과 `"openrun": true` |
| `types` | 특히 잘 맞는 MBTI (없어도 장르 궁합으로 추천돼요) |
| `months` | 특히 추천하고 싶은 달 (선택) |
| `poster` | 포스터 이미지 주소 (선택, 없으면 픽셀 아이콘이 나와요) |

> ⚠️ 쉼표(`,`)와 따옴표(`"`)를 빠뜨리면 파일이 깨져요. 깨지면 게임에 들어 있는 기본 목록으로 자동 대체되니 걱정 마세요. 붙여넣기 전에 jsonlint.com 에서 검사해 볼 수 있어요.

## 🔄 KOPIS 실시간 공연 자동 반영 (선택)

`shows.json`만으로도 잘 작동해요. 손대지 않아도 매달 새 공연이 자동으로 추가되길 원하면 KOPIS 키를 연결해요.

1. KOPIS(kopis.or.kr) → 오픈API 메뉴에서 **인증키를 신청**해요 (무료).
2. 버셀 프로젝트 → **Settings → Environment Variables**에 아래처럼 추가해요.
   - Key: `KOPIS_KEY`
   - Value: 발급받은 인증키
3. **Deployments** 탭에서 최신 배포의 `⋯ → Redeploy`를 눌러요.

연결하면:
- 서울에서 공연 중이거나 30일 안에 개막하는 뮤지컬·연극·대중음악·클래식·무용 공연을 자동으로 가져와요. **진짜 포스터**와 **예매처 링크**도 함께 와요.
- `shows.json`에 직접 넣은 공연이 항상 우선이고, 자리가 남으면 KOPIS 공연으로 채워요.
- 결과는 6시간마다 새로 받아와서 KOPIS 호출 한도를 아껴요.
- 아동 공연은 빠져요.
- 키는 서버에만 있어서 방문자에게 노출되지 않아요.

연결 확인: `내도메인/api/shows` 를 열었을 때 `"source":"kopis"` 가 보이면 성공이에요.

## 🧪 다른 날짜로 미리 보기

예: `https://내도메인/?date=2027-01-15`
